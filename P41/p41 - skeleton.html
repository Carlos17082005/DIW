1. Audio y vídeo en HTML5

Qué es / para qué sirve

Son etiquetas nativas introducidas en HTML5 que permiten incrustar y reproducir contenido multimedia directamente en el navegador sin necesidad de plugins externos.

Casos de uso típicos

Plataformas de streaming, reproductores de podcasts web, vídeos de fondo y tutoriales integrados...

Ventajas

Soporte nativo en todos los navegadores modernos, mejora la accesibilidad, esta mejor optimizado y permite controles personalizados mediante JavaScript.

Limitaciones

Dependencia de los códecs soportados por cada navegador y dificultad para unificar el diseño de los controles por defecto en distintos sistemas operativos.

Ejemplos reales (webs conocidas)

  • Netflix
  • SoundCloud

Conclusión personal

La adopción de los elementos multimedia de HTML5 marcó un antes y un después en la estandarización de la web, acabando con los problemas de seguridad y rendimiento de los plugins externos. Lo mejor seria usar siempre estas etiquetas frente a soluciones de terceros, ya que ofrecen el mejor equilibrio entre rendimiento nativo y control. Al poder manipular el estado del reproductor directamente mediante JavaScript, nos permite construir interfaces completamente adaptadas a la imagen de marca del proyecto.

2. Canvas

Qué es / para qué sirve

Un lienzo bidimensional de píxeles en HTML que no tiene contenido por sí mismo, sino que expone una API de JavaScript para dibujar trayectorias, cajas, círculos, texto o imágenes en tiempo real.

Casos de uso típicos

Renderizado de videojuegos en el navegador, manipulación fotográfica en vivo, visualización masiva de datos y renderizado 3D.

Ventajas

Rendimiento extremo. Al no crear nodos en el DOM por cada elemento dibujado, puede manejar miles de partículas u objetos moviéndose a 60 fotogramas por segundo sin que el navegador colapse.

Limitaciones

Opacidad total para la accesibilidad. No tiene un sistema de eventos por elemento.

Ejemplos reales (webs conocidas)

  • Agar.io
  • Figma

Conclusión personal

Canvas es una herramienta extraordinariamente potente, pero que debe usarse con precaución y solo cuando el caso de uso lo exija. Lo elegiría de forma exclusiva cuando me enfrente a cuellos de botella de rendimiento en el DOM; por ejemplo, si tengo que animar más de 500 o 1000 elementos simultáneamente. Sin embargo, por la pérdida de la accesibilidad nativa nunca lo usaría para construir elementos de interfaz de usuario tradicionales, reservándolo para la capa de visualización de datos intensiva, videojuegos o herramientas de dibujo.

3. SVG

Qué es / para qué sirve

Scalable Vector Graphics es un lenguaje de marcado basado en XML diseñado para describir gráficos vectoriales bidimensionales. En lugar de usar píxeles, usa fórmulas matemáticas para trazar la imagen, lo que lo hace mucho mas escalable.

Casos de uso típicos

Logotipos de empresas, sets de iconos de interfaces de usuario, ilustraciones técnicas, infografías que requieren interacción y mapas interactivos.

Ventajas

Se puede escalar infinitamente sin perder calidad. Tienen un peso en kilobytes mucho mas bajo que las imágenes. Al estar en el DOM, cada trazo se puede animar individualmente con CSS o manipular con JS.

Limitaciones

No es adecuado para fotografías complejas o imágenes con millones de colores y gradientes intrincados. Si el SVG tiene demasiados nodos, ralentizará el renderizado de la página.

Ejemplos reales (webs conocidas)

  • GitHub
  • Google Maps

Conclusión personal

Considero que el SVG es uno de los mayores aliados del diseño web moderno y responsivo. Mi postura es que cualquier gráfico que no sea una fotografía estricta debería ser un SVG. Lo usaría siempre para la identidad visual de un proyecto porque garantiza una nitidez absoluta independientemente del dispositivo del usuario. Además, podemos cambiar el color del logo de forma nativa, para ofecer una mejor experiencia con, por ejemplo, el tema claro y oscuro.

4. CSS Animations / Transitions

Qué es / para qué sirve

Funcionalidades nativas de CSS3. Las transiciones interpolan suavemente el paso de un estado A a un estado B. Las animaciones @keyframes permiten definir una línea de tiempo compleja con múltiples etapas y repeticiones sin necesidad de interacción previa.

Casos de uso típicos

Hover effects en botones y enlaces, loaders o spinners de carga, menús laterales que se deslizan, y animaciones de "entrada" de elementos a medida que se hace scroll.

Ventajas

Es muy declarativo y facil de leer. Esta muy bien optimisado.

Limitaciones

La interactividad es muy básica. Es difícil pausar, invertir o vincular una animación CSS al progreso del scroll del usuario o a las coordenadas precisas del ratón sin la ayuda de JavaScript.

Ejemplos reales (webs conocidas)

  • Aplee
  • Duolingo

Conclusión personal

Limitaría el uso de animaciones CSS estrictamente a aquellas transformaciones visuales que buscan dar un feedback inmediato al usuario. Dejaría el uso de librerías de animación complejas de JS solo para casos donde necesito secuenciar eventos muy sofisticados o hacer que la animación dependa de cálculos matemáticos en vivo.

5. JavaScript para interactividad

Qué es / para qué sirve

El lenguaje de programación nativo de la web. Escucha constantemente los eventos del sistema o del usuario y ejecuta lógica condicional para modificar el DOM o realizar peticiones a servidores en segundo plano.

Casos de uso típicos

Single Page Applications (SPAs) donde la página no recarga, validación compleja de formularios en tiempo real, drag & drop de elementos, y llamadas asíncronas a APIs REST.

Ventajas

Su versatilidad es infinita. Permite convertir un documento estático de texto en una aplicación de software completa, gestionando el estado de la aplicación, guardando datos en el navegador y ofreciendo interactividad sin límites.

Limitaciones

Si escribimos funciones JS muy pesadas o ineficientes, la página entera se congelará, frustrando al usuario. Además, si el usuario deshabilita JS del navegador, la web puede quedar inutilizable si no se ha diseñado con esto en mente.

Ejemplos reales (webs conocidas)

  • Gmail
  • Notion

Conclusión personal

Lo usaría invariablemente para la "lógica de negocio" del frontend y para interacciones de UI complejas que CSS simplemente no puede manejar, evitando añadir kilobytes de JavaScript para resolver problemas estilísticos o animaciones simples. Utilisaria JS como el pegamento inteligente que une la interfaz gráfica estática con los datos dinámicos del servidor.

6. APIs relacionadas

Incluye mínimo 2 APIs

API 1: Web Audio API

Qué hace: Es un sistema de alto nivel basado en la interconexión de "nodos de audio". Va mucho más allá del simple audio. Permite sintetizar sonidos desde cero, aplicar efectos espaciales en 3D, ecualizadores y analizar frecuencias en tiempo real para crear visualizadores visuales.

Casos de uso: Secuenciadores musicales web, cajas de ritmos online, y motores de sonido para videojuegos en el navegador.

Ejemplos reales: Spotify, Soundtrap

Conclusión personal: Tradicionalmente, manipular audio a este nivel requería descargar programas pesados, esta API abre la puerta a crear proyectos sumamente creativos e inmersivos. La usaría sin dudarlo en experiencias interactivo donde el sonido responda a las acciones del usuario.

API 2: (nombre)

Qué hace: Proporciona una interfaz para utilizar el estándar OpenGL ES en el navegador, permitiendo al código JavaScript comunicarse directamente con la GPU del usuario para renderizar gráficos complejos en 2D y 3D dentro de un canvas

Casos de uso: Lazy loading de imágenes para que solo se descarguen si el usuario llega a ellas, Infinite Scroll, y disparar animaciones justo cuando un elemento es visible.

Ejemplos reales: Google Earth, Spline Design

Conclusión personal: Rompe el paradigma de la web como un "documento plano" y la convierte en un espacio espacial. Aprovechar esta API en proyectos de e-commerce de alto nivel para asi eleva la percepción de calidad del producto.

API 3 (opcional): Intersection Observer API

Qué hace:Te avisa eficientemente cuando un elemento entra o sale de la pantalla.

Casos de uso: Configuradores de productos 3D, simulaciones físicas, data-viz a gran escala, experiencias web inmersivas y filtros de realidad aumentada en el navegador.

Ejemplos reales: Pinterest, Amazon

Conclusión personal: Es una de las APIs modernas más útiles. La utilizaría por defecto en cualquier proyecto web para optimizar la carga de imágenes, garantizando que el usuario gaste menos datos móviles y la web cargue casi instantáneamente.
